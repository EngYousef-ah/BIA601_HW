# مشروع توزيع المهام على الموظفين 

## المتطلبات
- المكتبات: `numpy` و `matplotlib`

# pip install numpy matplotlib

## طريقة التشغيل
```bash
python main.py            # التجارب الكاملة (10 تكرارات لكل خوارزمية، ثلاثة أحجام) 
python main.py --quick    # تجربة سريعة للتأكد من عمل الكود
python main.py --runs 30  # زيادة عدد التكرارات
```
